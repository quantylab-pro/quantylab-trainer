# 우선순위 실행 결과

1. 실제 호가 비용: 시그널 생성 1분 이후의 최우선 매도호가로 진입, 생성 6분 이후 최우선 매수호가로 청산하도록 바꿨다. 각 조회 시점 허용 오차는 45초이며 날짜를 넘겨 연결하지 않는다. 수신 완료 시각 기준 평가다. 추가 비용 2/9/18bp를 각각 평가했다. 이는 실제 호가를 사용한 연구 시뮬레이션이지 체결 보장/시장충격/수량별 호가 소진 모델은 아니다.
2. 잔량 피처: 최우선/3/5/10단계 불균형, 미시가격 괴리, 잔량 변화 추가. 잔량 변화는 120초 초과 간격이나 날짜 경계에서 리셋한다. 이를 실제 주문흐름으로 간주하지 않는다.
3. NAV: 수신 시각 기준 backward as-of 결합 구현. 특수 시각 888888, 미래 공급자 시각, 120초 초과 오래된 자료 제외. 기존 NAV는 16:10 수신 / 15:30 전후 공급자 기록이라 유효 결합 0행. NAV 효과 비교는 실행하지 못했다. 장중 수신 NAV의 추가 수집이 필요하며 이번 변경으로 운영 Prefect 수집을 확장하지는 않았다.
4. 날짜별 검증: 3일 이상이면 첫 2일 이후 날짜를 순차 평가하는 코드 구현. 현재 분석용 스냅샷은 9/14 하루뿐이므로 날짜 외부 검증은 불가능하다. 대신 앞 시간 학습/뒤 시간 평가를 실행하고 학습 라벨 종료가 평가보다 최소 1분 앞서도록 분리했다. 이 결과를 다일 검증으로 표기하지 않았다.

## 실험

유효 1,871행. 기본 피처 / 잔량 피처 × 추가 비용 2/9/18bp, 총 6비교. 현재 스프레드 10bp 이하이면서 예상 호가 기준 수익이 추가 비용+2bp를 넘는 경우만 진입한다. 선택 임계값은 이번 실험 전에 고정했다. 종목별 미청산 거래가 있으면 신규 진입을 하지 않는다.

모든 비교에서 평가 구간 거래 0회. 비용을 감안한 진입 근거를 모델이 만들지 못했으며 개선 성공이나 수익성을 주장할 수 없다. 과거 시뮬레이터의 매분 체결과 달리 이 실험은 비동기 스냅샷이 존재하는 시점만 평가한다.
