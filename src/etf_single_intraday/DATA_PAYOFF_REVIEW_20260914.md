# 호가·체결강도와 기대손익 모델 검토

## 수행한 실험

비용 초과 확률 × 해당 조건의 수익 크기 + 나머지 확률 × 해당 조건의 손익 크기로 기대수익을 계산하는 3모델 구조를 추가했다. 5/15/30분 × 임계값 2개, 총 6설정을 순차 3구간 검증했다. 고정 왕복 비용 18bp와 36bp, 다음 분 시가 체결 및 지연 스트레스를 유지했다.

선택된 5분 모델은 과거 검증 +0.04766%, -0.03043%, -0.02498%. 최근 18거래일에는 1회 거래뿐이며 18bp 기준 +0.00010%, 36bp -0.00034%. 개선 성공으로 판단하지 않는다. 확률 보정은 별도 실시하지 않았고, 조건부 손익은 ±3%로 절삭한 목표다. 최근 구간은 반복 관찰한 회고 평가다.

## 실제 수집 데이터 분석

개발 서버 보존본과 운영 서버 스냅샷 복사본을 함께 분석했다. 2026-09-14 하루, 26종, 5,602개. 원본 오류 0개, 저장된 호가 freshness 표시는 100%지만 이는 날짜 없는 공급자 시간차 기준이다.

- 스프레드 중앙값 8.81bp, 90백분위 19.68bp, 99백분위 31.95bp.
- 체결강도 최신 기록 지연 중앙값 40.5초, 90백분위 164.9초, 99백분위 524초. 따라서 호가 최신 여부만으로 체결강도 최신 여부를 보장할 수 없다.
- 피처 이용 시각은 호가·체결강도 수신 시각의 최댓값. 체결강도 기록은 그 시각 이전 것만 선택하고 120초 초과는 결측 처리.
- 이후 5분~6분30초 호가와 연결한 4,927개 겹치는 표본에서 중간가격 수익률과 Spearman 상관: 최우선 잔량 불균형 0.1068, 전체 잔량 불균형 0.1127, 체결강도 0.0088. 인과성·통계적 유의성·독립 거래를 뜻하지 않는다.

앞 시간대 3,028개 학습 / 뒤 시간대 1,725개 평가. 학습 목표의 종료가 평가 시작보다 최소 1분 앞서도록 분리했다. 같은 날 내부 비교이며 다른 날 일반화 검증이 아니다.

| 입력 | 평가 MSE (bp²) | 비용 초과 예상 신호 | 해당 신호 평균 호가 기준 순수익 |
|---|---:|---:|---:|
| 스프레드 + 직전 중간가격 변화 | 238.03 | 0 | 해당 없음 |
| + 최우선·전체 잔량 불균형 | 240.65 | 17 | -6.82bp |
| + 체결강도 | 240.70 | 21 | -8.37bp |

매수호가가 아니라 최우선 매도호가로 진입하고 미래 최우선 매수호가로 청산하는 호가 기준 평가이며, 추가 수수료는 예시 2bp이다. 실제 체결·잔량 소진·시장충격·포지션 중복을 재현한 백테스트는 아니다. 이 비교에서 예측력 개선을 확인하지 못했다. 호가의 당장 유용한 용도는 비용/유동성 필터이며 수익 예측 피처의 유효성은 미확정이다.

## 추가 데이터 우선순위

1. 기존 원본 10단계 호가: 깊이별 불균형, 미시가격, 잔량 변화. 별도 API 호출 없이 생성 가능. 단순 스냅샷 차이를 취소 주문/실제 주문흐름으로 단정하지 말 것.
2. ETF 시간대별 NAV·괴리율·추적오차: 공식 로컬 스펙 ka40006에서 확인. 요청은 종목코드이며 과거 날짜 인자가 없어 장기 과거 조회 가능성을 주장하지 않는다. 해외자산 ETF의 NAV 신선도와 기초시장 휴장 여부를 별도 확인할 것.
3. 장중 프로그램 순매수: ka90008은 종목·날짜·금액/수량 인자를 지원한다. 날짜 인자만으로 실제 과거 보존 기간과 시점 정합성을 보장할 수 없으므로 샘플 검증 필요.
4. 지수/기초자산 분봉, 선물 베이시스, 환율: 공통 시장 요인을 분리하는 데 사용할 후보. 거래 시간/지연/수신 시각과 사용 권한, 역사적 가용성을 확인한 후 도입.
5. 전일 AI 분석: 점수보다 공시·실적·정책 이벤트와 근거 자료의 발표 시각을 함께 저장. 사후 수정본을 과거 피처로 사용하지 말 것. 이번 실험에는 미포함.

## 산출물

실제 조회 파일럿: ka40006은 102110/396500 각 첫 페이지 20개 행을 반환했고 NAV/괴리율 필드 존재를 확인했다. 첫 행 시간은 `888888`로 정상 시각이 아니므로 집계/특수 행을 그대로 분봉에 결합하면 안 된다. ka90008의 102110·20260911 요청은 0개 행이었다. 해당 과거 프로그램 데이터를 확보했다고 주장하지 않는다. 무제한 페이지 조회 파일럿은 응답 대기로 종료하고, 요청별 제한 시간과 첫 페이지 한정 방식으로 다시 실행했다.

- `output/intraday_payoff_20260914/`: 기대손익 모델·검증 보고서·거래 기록
- `output/intraday_micro_audit_20260914_v2/`: 정규화 스냅샷, 미래 연결 표본, 품질 보고서, ablation.json
- `output/microstructure_remote_20260914/`: 운영 원본의 읽기 전용 분석용 복사본. 운영 수집 변경 없음.
- `collect_context_pilot.py`: 소수 NAV/프로그램 조회 가능성 점검용. 운영 자동 수집에 추가하지 않음.

결론: 이번에도 실전 승인 가능한 모델은 확보하지 못했다. 데이터를 더 모으는 것과 동시에 실제 비용을 넘는지, 여러 날짜에 재현되는지, 피처 제거 대비 개선되는지를 분리 평가해야 한다.
