# 청산 수정 및 추가 데이터 점검 — 2026-09-15

## 수정 및 재현

`minute_engine.simulate`의 사전 예정된 15:15 청산을 신호 지연과 분리했다.
포지션이 있으면 15:15 시가에서 청산하며, 해당 봉이 없으면 이후 첫 관측
시가를 사용한다. 기존 대기 청산 주문보다 세션 마감이 우선한다.
마감 이후 관측이 전혀 없으면 기존 truncated 청산 표시를 유지한다.

관련 테스트 23개 및 subtest 4개 통과. 1/2분 지연, 15:15 봉 결측,
대기 중인 일반 청산과의 충돌을 검증했다.

고정 후보 advanced(5분)와 aligned(30분)를 비용 18bp, 18bp+2분 지연,
36bp로 각각 재평가했다. 6조건 모두 기존 보고서와 집계 지표가 같았다.
이번 수정은 경계조건 오류 수정이며 수익성 향상을 의미하지 않는다.
모델 재학습이나 임계값 변경은 수행하지 않았다.

재현:

```bash
python -m quantylab.trainer.etf_single_intraday.session_exit_audit \
  --runs output/intraday_minute_20260914_advanced output/intraday_minute_20260914_aligned \
  --output output/new_session_exit_audit
```

산출물: `output/intraday_session_exit_20260915/report.json` 및 거래/일간 CSV.
