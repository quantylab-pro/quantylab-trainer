## 데이터

고정 대형주 30종목의 키움 주식 분봉을 2026-01-29~09-23 범위로 백필했다. API 오류 0건, 백필 응답 1,820,182행이며 기존 장중 적재분을 포함한 최종 DB 점검은 1,854,966행, 30종목 각 160거래일이었다. 세션별 분봉 수 중앙값은 각 종목 381개다. 종목 원천은 `HHMMSS`, ETF 데이터는 `HHMM`으로 저장돼 종목 로더가 분 단위로 정규화한다.

## 평가 방법

- 단일 공유 회귀모델이 종목별 신호를 출력한다. 포트폴리오 성과가 아니다.
- 완료 분봉 피처 뒤 다음 분봉 시가에 진입하고, 5/15/30분 보유 후 다음 시가에 청산한다. 신규 진입은 15:00 전, 당일 청산은 15:15 세션 제한을 사용한다.
- 4/30, 5/29, 6/30 학습 종료점을 둔 세 확장 검증 fold에서 horizon·진입 임계값을 고르고, 7/31까지 학습한 후보를 8/3~9/23 잠금 구간에서 평가했다.
- 비용은 왕복 29bp 대칭 근사치다. 기존 주식 swing 설정의 편도 수수료 1.5bp, 매도세 20bp, 편도 슬리피지 3bp 합계지만 실제 매수·매도 비대칭과 호가 체결을 복원하지 않는다.
