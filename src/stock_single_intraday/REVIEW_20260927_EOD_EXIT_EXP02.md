# stock-single-intraday-v1 / eod-exit-exp02

## 가설과 계약

exp01에서 거래 수를 확보했던 HGB 분류기 확률 0.38과 0.42를 고정하고, 당일 종가 청산에 손절·익절·추적청산을 추가하면 비용 후 손실이 줄어드는지 확인했다. 기준 비용은 모든 과거 날짜에 현행 KOSPI 왕복 29bp다. 진입은 완료된 5분봉 신호 후 다음 봉 시가다. 청산 조건은 완료된 봉의 종가에서 판단하고 다음 봉 시가에 체결한다. 봉 내부 고가·저가로 먼저 청산한 것으로 계산하지 않았다.

8개 walk-forward 폴드에 확률 2개와 청산 규칙 6개를 비교했다. 매 폴드마다 HGB 분류기는 한 번만 학습했다. 기존 검증 구간을 다시 사용한 탐색이므로 독립 잠금 평가가 아니다.

## 결과

12개 설정 모두 품질 게이트 탈락. 확률 0.38 신호는 1,410회 거래했고 당일 말 청산은 pooled 거래당 -43.6bp였다. 0.5% 손절 후 다음 봉 시가 청산은 -24.3bp로 손실을 줄였지만 양의 기대값 폴드는 2/8뿐이었다. 확률 0.42 신호는 802회 거래했고, 1% 손절이 가장 나은 -30.0bp였지만 양의 기대값 폴드는 1/8이다. 익절·추적청산도 양의 안정적 기대값을 만들지 못했다.

이 실험은 포지션 보유 중 다음 5분봉이 없으면 다음 관측 봉 시가에 청산했다. 이는 exp01의 종가까지 보유 정책과 달라 당일 말 청산 숫자도 정확히 같지 않다. 결측 이후 실제 체결 가능 시각은 분봉만으로 확인할 수 없다.

## 데이터 품질 진단

전체 7,783개 종목·일 세션 중 516개(6.6%)에서 첫 관측 봉과 마지막 관측 봉 사이에 5분봉 결측이 있었고, 내부 결측은 총 2,212개 봉이었다. 2026-03-04에는 11:20–11:45 시작 봉 6개, 2026-03-09에는 10:30–11:00 시작 봉 7개가 30개 종목 모두에서 빠졌다. 2025-11-13과 2026-01-02처럼 10:00에 시작해 이후 연속된 세션은 내부 결측으로 세지 않았다.

사후적으로 내부 결측이 없는 세션의 거래만 남겨도 확률 0.38·0.5% 손절은 1,299회, 거래당 -26.3bp, 양의 기대값 폴드 1/8이었다. 이 사후 필터는 진입 시점에 미래 결측 여부를 알 수 없으므로 실제 전략 조건으로 사용하지 않는다. 원본 전량 결과와 품질 민감도 모두 후보 없음이라는 판단에 일치한다.

결과는 `output/stock_single_intraday/stock-single-intraday-v1/eod-exit-exp02/`의 `report.json`, `trades.csv`, `bar_gap_audit.json`과 8개 fold 체크포인트에 보존했다. 정식 버전은 v1이고 배포 승인은 false다.
